# v1.6.0 forward test (informal, pre-harness)

These files record the clean-context answers and review notes used while preparing v1.6.0. They predate the evaluation harness: `report.json` uses schema version 1, was recorded from a working tree with uncommitted changes, and has no `run.json`, so `scripts/validate-evidence.sh` does not validate it.

Treat this folder as informal design notes, not as evidence of model behavior. Comparative claims need a harness run in the current schema; see `evals/README.md`.
