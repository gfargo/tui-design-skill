## Example app (`entry_app.py`)

```python
from textual.app import App, ComposeResult
from textual.containers import Vertical
from textual.message import Message
from textual.widgets import Button, Input, Label, Select


class EntryForm(Vertical):
    class Submitted(Message):
        def __init__(self, person_name: str, category: str) -> None:
            super().__init__()
            self.person_name = person_name
            self.category = category

    def compose(self) -> ComposeResult:
        yield Input(placeholder="Name", id="name")
        yield Select(
            [("Customer", "customer"), ("Supplier", "supplier")],
            value="customer",
            allow_blank=False,
            id="category",
        )
        yield Label("", id="error")
        yield Button("Submit", id="submit")

    def on_button_pressed(self, event: Button.Pressed) -> None:
        if event.button.id != "submit":
            return
        name = self.query_one("#name", Input).value.strip()
        error = self.query_one("#error", Label)
        if not name:
            error.update("Name is required")
            error.add_class("visible")
            return
        error.update("")
        error.remove_class("visible")
        category = self.query_one("#category", Select).value
        self.post_message(self.Submitted(name, category))


class EntryApp(App):
    def compose(self) -> ComposeResult:
        yield EntryForm()
```

## Tests (`test_entry_app.py`)

```python
from textual.message import Message
from textual.widgets import Input, Label, Select

from entry_app import EntryApp, EntryForm


async def test_empty_name_shows_validation_error():
    app = EntryApp()
    async with app.run_test() as pilot:
        await pilot.click("#submit")
        await pilot.pause()

        error = app.query_one("#error", Label)
        assert str(error.content) == "Name is required"
        assert error.has_class("visible")


async def test_submit_posts_message_with_form_values():
    captured: list[Message] = []
    app = EntryApp()

    async with app.run_test(message_hook=captured.append) as pilot:
        # Type like a real user does
        await pilot.click("#name")
        await pilot.press(*"Ada Lovelace")

        # Setting the Select directly is easier than driving its dropdown
        app.query_one("#category", Select).value = "supplier"

        await pilot.click("#submit")
        await pilot.pause()

    submitted = [m for m in captured if isinstance(m, EntryForm.Submitted)]
    assert len(submitted) == 1
    assert submitted[0].person_name == "Ada Lovelace"
    assert submitted[0].category == "supplier"


async def test_invalid_form_posts_no_message():
    captured: list[Message] = []
    app = EntryApp()
    async with app.run_test(message_hook=captured.append) as pilot:
        await pilot.click("#submit")
        await pilot.pause()

    assert not any(isinstance(m, EntryForm.Submitted) for m in captured)
```

## How it works

- **`app.run_test()`** runs the app headless and gives you a `Pilot`. Use it to click (`pilot.click("#id")`), press keys (`pilot.press("tab", "enter")`) or resize the terminal (`pilot.resize_terminal(w, h)`).
- **`await pilot.pause()`** waits until pending messages have been processed. Call it after an action and before your asserts, or you'll get flaky tests.
- **`message_hook=`** is called with every message the app processes. It's the easiest way to check "the right message was posted" without changing your app. Filter the list by type, because you'll also get `Click`, `Key`, `Button.Pressed` and so on.
- **Typing vs. setting values:** `pilot.press(*"text")` goes through the real key handling, so the Input needs focus first. That's why the test clicks it. Setting `.value` directly is fine for widgets like `Select`, where driving the overlay with keys adds nothing to the test.
- **Messages with a `name` field:** I called the attribute `person_name` so it can't clash with attributes on `Message`. Using `name` is probably fine, but this rules out surprises.
- **Built-in validators:** if you use `Input(validators=[...])` instead of a custom check, you can assert on `input.is_valid` or `input.has_class("-invalid")`.

## Optional: snapshot tests

To catch layout regressions (for example, the error label not appearing or being styled wrong), install `pytest-textual-snapshot`:

```python
def test_error_looks_right(snap_compare):
    assert snap_compare(EntryApp(), press=["tab", "tab", "tab", "enter"])
```

The first run saves an SVG of the screen, and later runs fail if the screen changes. Update the saved snapshot with `pytest --snapshot-update`.
