## 1. Setup

Textual's test harness is async, so you need an async pytest plugin:

```bash
pip install pytest-asyncio
```

## 2. The form being tested (for reference)

```python
# app.py
from textual.app import App, ComposeResult
from textual.containers import Vertical
from textual.message import Message
from textual.widgets import Button, Input, Label, Select

ROLES = [("Admin", "admin"), ("Editor", "editor"), ("Viewer", "viewer")]


class EntryForm(Vertical):
    class Submitted(Message):
        def __init__(self, name: str, role: str) -> None:
            self.name = name
            self.role = role
            super().__init__()

    def compose(self) -> ComposeResult:
        yield Input(placeholder="Name", id="name")
        yield Label("", id="name-error")
        yield Select(ROLES, id="role", allow_blank=False)
        yield Button("Submit", id="submit")

    def on_button_pressed(self, event: Button.Pressed) -> None:
        name = self.query_one("#name", Input).value.strip()
        error = self.query_one("#name-error", Label)
        if not name:
            error.update("Name is required")
            self.query_one("#name", Input).add_class("-invalid")
            return
        error.update("")
        self.query_one("#name", Input).remove_class("-invalid")
        role = self.query_one("#role", Select).value
        self.post_message(self.Submitted(name, role))


class EntryApp(App):
    def compose(self) -> ComposeResult:
        yield EntryForm()
```

## 3. The tests

```python
# test_app.py
from textual.widgets import Input, Label, Select

from app import EntryApp, EntryForm


class RecordingApp(EntryApp):
    """Test harness: records the messages that bubble up to the app."""

    def __init__(self) -> None:
        super().__init__()
        self.submitted: list[EntryForm.Submitted] = []

    def on_entry_form_submitted(self, message: EntryForm.Submitted) -> None:
        self.submitted.append(message)


async def test_empty_name_shows_validation_error():
    app = RecordingApp()
    async with app.run_test() as pilot:
        await pilot.click("#submit")
        await pilot.pause()  # let pending messages and refreshes finish

        error = app.query_one("#name-error", Label)
        assert "Name is required" in str(error.content)
        assert app.query_one("#name", Input).has_class("-invalid")
        assert app.submitted == []  # nothing was posted


async def test_submit_posts_message_with_values():
    app = RecordingApp()
    async with app.run_test() as pilot:
        await pilot.click("#name")       # focuses the Input
        await pilot.press(*"Alice")      # types one key at a time
        app.query_one("#role", Select).value = "editor"
        await pilot.click("#submit")
        await pilot.pause()

        assert len(app.submitted) == 1
        msg = app.submitted[0]
        assert (msg.name, msg.role) == ("Alice", "editor")
        assert str(app.query_one("#name-error", Label).content) == ""
```

## How it works

- **`app.run_test()`** runs the app headless and gives you a `Pilot`. Pass `size=(100, 40)` if your layout needs room, because `click` fails on widgets that are off-screen.
- **Pilot actions**: `click(selector)`, `press("tab", "enter", ...)`, `hover`, and `pause()`. Call `await pilot.pause()` before assertions so queued messages get processed. It's the fix for most flaky tests.
- **Checking messages**: messages bubble from the widget up to the app. A subclass that adds an `on_<widget>_<message>` handler is the simplest way to capture them without changing production code. The handler name comes from the class names: `EntryForm.Submitted` becomes `on_entry_form_submitted`.
- **Setting Select**: assigning `.value` directly is the reliable way. To test the keyboard interaction too, focus it and use `await pilot.press("enter", "down", "enter")`. That test depends on option order.
- **Checking state**: use `app.query_one(...)` and assert on `.value`, `.content` (on a `Label`/`Static`), classes, or `.display`.

## Alternatives

- If you use Textual's built-in validators (`Input(validators=[Length(minimum=1)])`), check `input.is_valid` or the `-invalid` class instead. Note that an untouched empty Input isn't validated until it changes, is submitted, or loses focus. That's why the example validates in the button handler.
- For visual regressions, add `pytest-textual-snapshot` and use `snap_compare(app, press=[...])`. It saves an SVG snapshot of the screen and fails the test when the rendering changes.
