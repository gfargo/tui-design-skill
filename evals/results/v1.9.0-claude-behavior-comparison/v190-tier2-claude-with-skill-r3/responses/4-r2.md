**Short answers:** don't take over the screen. Render inline below the prompt, capped at about 10 rows. When it exits, erase the picker completely and leave one receipt line naming the branch. The interactive UI goes to stderr (or `/dev/tty`). The branch name goes to stdout and nothing else does.

## 1. Full screen or inline?

Go inline. lazygit uses the alternate screen because people stay in it for a while, moving between panels. Your tool gets called up, used for two seconds, and closed, which is the fzf `--height` / atuin pattern.

A correction to one assumption: the alternate screen doesn't erase the command the user typed. When it closes, the terminal puts the old screen back, prompt included. Inline still wins for three reasons:

- **Context stays visible while they pick.** The `git status` or failing test output they're reacting to stays on screen.
- **No flash.** Swapping the whole screen for a 10-row list is jarring.
- **The receipt lands where they expect it**, directly under the command, with nothing in between.

A full-screen buffer is only worth it if you later add a large preview (a diff or log per branch). Even then, a height cap with a side preview usually works fine.

## 2. What the terminal looks like after exit

The rule from the skill: either erase the UI cleanly or leave a one-line receipt. Never leave a half-drawn, dead UI in scrollback.

While picking:
```
~/app (main) $ gsw
> log█                                          4/23
› feature/login-redirect                 2 hours ago
  fix/logout-race                          yesterday
  chore/log-rotation                      3 days ago
  feature/blog-import                    2 weeks ago
↑↓ move · enter pick · esc cancel
```

After pressing Enter:
```
~/app (main) $ gsw
› feature/login-redirect
Switched to branch 'feature/login-redirect'
~/app (feature/login-redirect) $
```

The command and the branch both stay in scrollback, and none of the picker's frames do.

### How the output streams split
- **Picker UI → stderr** (`tea.WithOutput(os.Stderr)`, which is how gum works) **or `/dev/tty`** (how fzf works). Use `/dev/tty` if you want it to keep working when someone runs it with `2>/dev/null`.
- **Branch name → stdout**: one plain line with no ANSI codes. That's what makes `git switch "$(pick-branch)"` work.
- **Receipt → stderr, but only when stdout isn't a terminal.** If stdout is a terminal, the branch printed on stdout already serves as the receipt, so printing it again would show it twice.
- **Exit codes:** 0 when a branch is picked, 1 when the user presses Esc or nothing matches, 130 for Ctrl+C. Shell wrappers can then skip the `git switch`.

### Bubble Tea v2 sketch
```go
func (m model) View() tea.View {
    if m.done {
        return tea.NewView("") // final frame is empty → picker is erased
    }
    return tea.NewView(m.render()) // inline is the default; never set AltScreen
}

func main() {
    branches, err := recentBranches() // git for-each-ref --sort=-committerdate; run before the UI starts
    if err != nil { fmt.Fprintln(os.Stderr, "pick-branch:", err); os.Exit(2) }
    if len(branches) == 0 { fmt.Fprintln(os.Stderr, "pick-branch: no other branches"); os.Exit(1) }

    final, err := tea.NewProgram(newModel(branches), tea.WithOutput(os.Stderr)).Run()
    if errors.Is(err, tea.ErrInterrupted) { os.Exit(130) } // Update returns tea.Interrupt on ctrl+c
    if err != nil { fmt.Fprintln(os.Stderr, "pick-branch:", err); os.Exit(2) }

    m := final.(model)
    if m.choice == "" { os.Exit(1) } // esc
    fmt.Println(m.choice)
    if !term.IsTerminal(int(os.Stdout.Fd())) {
        fmt.Fprintf(os.Stderr, "› %s\n", m.choice)
    }
}
```
`Run()` handles restoring the terminal on every exit path, including panics, so you don't need to add your own cleanup. Don't print anything while `Run()` is active. Exit quietly with a message on stderr when there are zero branches, rather than opening an empty picker.

## Layout checks

**Clutter:** no border at all, since the inline region already has natural edges. The selection is shown two ways, a `›` on the current row plus reverse video, so it still reads under `NO_COLOR`. Don't add per-row icons or a "Branch" header. All the chrome is one prompt/count line and one hint line.

**Narrow terminals:**
- **80×24:** height is `min(matches, 10) + 2`. The relative time is right-aligned.
- **60-column tmux split:** drop the time column first. Truncate long names with `…` measured by cell width (`lipgloss.Width`, not `len`).
- **Under about 30 columns or 4 free rows:** show `terminal too small` on stderr and exit 1 rather than drawing a broken list.

