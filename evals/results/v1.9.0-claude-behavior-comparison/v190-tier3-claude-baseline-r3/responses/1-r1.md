## First run with no key

Look for the key in this order, and only prompt if every source comes up empty:

1. A `--api-key` flag
2. An environment variable such as `MYCLI_API_KEY`
3. The stored credential (keychain or file, covered below)
4. **Prompt**, but only if the session is interactive

**If it's not interactive, don't prompt.** In CI, a pipe or a cron job, a prompt either hangs or fails in a confusing way. Exit non-zero with a message that tells the user exactly how to fix it:

```
Error: no API key configured.
  Set MYCLI_API_KEY, pass --api-key, or run `mycli auth login`.
  Get a key at https://example.com/settings/keys
```

**If it is interactive, keep the prompt short and helpful:**
- Say in one line why you need the key, and link to where they can get one.
- Mask the input.
- Check the format (not empty, correct prefix) as they type.
- If possible, make one cheap API call to confirm the key works before saving it. That way a typo doesn't get stored.
- Say where you saved it.
- **Then finish the command they originally ran.** Don't make them run it again.
- If they press Ctrl+C, exit quietly, not with a stack trace.

Also add `mycli auth login`, `logout` and `status` commands. That way the first-run prompt isn't the only way to set, rotate or remove the key.

```go
import (
	"errors"
	"fmt"
	"os"
	"strings"

	"github.com/charmbracelet/huh"
	"golang.org/x/term"
)

func ensureAPIKey(flagKey string) (string, error) {
	if flagKey != "" {
		return flagKey, nil
	}
	if k := os.Getenv("MYCLI_API_KEY"); k != "" {
		return k, nil
	}
	if k, err := loadKey(); err == nil && k != "" {
		return k, nil
	}

	if !term.IsTerminal(int(os.Stdin.Fd())) || !term.IsTerminal(int(os.Stdout.Fd())) {
		return "", errors.New("no API key configured; set MYCLI_API_KEY, pass --api-key, or run `mycli auth login`")
	}

	var key string
	err := huh.NewInput().
		Title("Enter your API key").
		Description("mycli needs an API key. Create one at https://example.com/settings/keys").
		EchoMode(huh.EchoModePassword).
		Validate(func(s string) error {
			s = strings.TrimSpace(s)
			if s == "" {
				return errors.New("key is required")
			}
			if !strings.HasPrefix(s, "sk_") {
				return errors.New(`keys start with "sk_"`)
			}
			return nil
		}).
		Value(&key).
		Run()
	if errors.Is(err, huh.ErrUserAborted) {
		os.Exit(130)
	}
	if err != nil {
		return "", err
	}
	key = strings.TrimSpace(key)

	if err := verifyKey(key); err != nil { // one cheap authenticated request
		return "", fmt.Errorf("that key didn't work: %w", err)
	}
	where, err := saveKey(key)
	if err != nil {
		return "", err
	}
	fmt.Fprintf(os.Stderr, "✓ API key saved to %s\n", where)
	return key, nil
}
```

## Where to store the key

**Use the OS keychain first, with a locked-down file as the fallback.**

**Keychain:** use [`github.com/zalando/go-keyring`](https://github.com/zalando/go-keyring). It works with macOS Keychain, Windows Credential Manager and Linux Secret Service, so the key is encrypted at rest and never sits in a plain file.

**File fallback:** use this when there's no keyring, which is common on headless Linux, in containers and over SSH.
- Put it at `$XDG_CONFIG_HOME/mycli/credentials`, or `~/.config/mycli/credentials` if that variable isn't set. Go's `os.UserConfigDir()` returns `~/Library/Application Support` on macOS, but most CLI users expect `~/.config`.
- Set the directory to `0700` and the file to `0600`.
- Write to a temp file and rename it over the real one, so a crash can't leave a half-written file.
- Keep credentials in their own file, separate from settings, so people can share or commit their config without leaking the key.

```go
import (
	"errors"
	"os"
	"path/filepath"

	"github.com/zalando/go-keyring"
)

const service, user = "mycli", "api-key"

func saveKey(key string) (string, error) {
	if err := keyring.Set(service, user, key); err == nil {
		return "system keychain", nil
	}
	dir, err := configDir()
	if err != nil {
		return "", err
	}
	if err := os.MkdirAll(dir, 0o700); err != nil {
		return "", err
	}
	path := filepath.Join(dir, "credentials")
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, []byte(key+"\n"), 0o600); err != nil {
		return "", err
	}
	return path, os.Rename(tmp, path)
}

func loadKey() (string, error) {
	if k, err := keyring.Get(service, user); err == nil {
		return k, nil
	} else if !errors.Is(err, keyring.ErrNotFound) {
		// keyring unavailable; fall through to file
	}
	dir, err := configDir()
	if err != nil {
		return "", err
	}
	b, err := os.ReadFile(filepath.Join(dir, "credentials"))
	return strings.TrimSpace(string(b)), err
}

func configDir() (string, error) {
	if x := os.Getenv("XDG_CONFIG_HOME"); x != "" {
		return filepath.Join(x, "mycli"), nil
	}
	home, err := os.UserHomeDir()
	return filepath.Join(home, ".config", "mycli"), err
}
```

**Things to avoid:**
- Editing the user's shell rc files to export the key.
- Printing the key in logs, `--verbose` output or error messages. Show only the last 4 characters at most, for example in `auth status`.
- Storing it in your main `config.yaml`.

`auth logout` should delete both the keychain entry and the credentials file.
