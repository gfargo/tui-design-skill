No—`RestoreTerminal()` has a misleading name for this purpose. It **resumes Bubble Tea’s terminal mode after `ReleaseTerminal()`**, including restarting input and rendering. Calling it after `Run()` can undo cleanup.

For normal use, simply write:

```go
p := tea.NewProgram(model)
_, err := p.Run()
return err
```

`Run()` handles terminal cleanup and, by default, Bubble Tea catches panics in the execution paths it manages.

If you intentionally disable that recovery so panics propagate, use `Kill()` as the cleanup guard:

```go
p := tea.NewProgram(model, tea.WithoutCatchPanics())
defer p.Kill()

_, err := p.Run()
return err
```

`Kill()` shuts down the program and restores the terminal; it does not recover the panic.

One limitation: a defer around `Run()` cannot protect against an unrecovered panic in an arbitrary goroutine you start yourself. Handle those panics within that goroutine. Neither approach can guarantee cleanup after `os.Exit` or `SIGKILL`.
