Remove the defer. **`RestoreTerminal()` restores Bubble Tea’s control of the terminal**, rather than restoring the user’s shell. It pairs with `ReleaseTerminal()` for temporary handoffs; calling it after shutdown can re-enable TUI terminal modes.

Use:

```go
p := tea.NewProgram(model)
_, err := p.Run()
return err
```

`Run()` manages terminal cleanup on normal exit, errors, and its default recovered-panic paths. Keep that recovery enabled; don’t add `tea.WithoutCatchPanics()` unless you deliberately take responsibility for cleanup. Quit from `Update` by returning `tea.Quit`, and avoid `os.Exit` while the UI is running.

For an editor or shell handoff, prefer `tea.ExecProcess(...)`. Reserve `ReleaseTerminal()` / `RestoreTerminal()` for manual temporary handoffs.

This protects framework-managed panic paths; a panic in an independently spawned goroutine cannot be recovered by a defer around `Run()`.
