Remove the defer. **`RestoreTerminal()` restores Bubble Tea’s terminal ownership**, resuming its modes after `ReleaseTerminal()`. It does not restore the user’s shell and can re-enable terminal modes after `Run()` has cleaned up.

Use:

```go
p := tea.NewProgram(model)
_, err := p.Run()
return err
```

`Run()` manages terminal cleanup on normal exit, errors, and panics caught by Bubble Tea’s default recovery. Keep that recovery enabled; don’t use `tea.WithoutCatchPanics()` unless you deliberately take responsibility for panic cleanup.

For quitting from `Update`, return `tea.Quit`. For temporarily handing the terminal to an editor or shell, prefer `tea.ExecProcess(...)`; `ReleaseTerminal()` / `RestoreTerminal()` are the lower-level handoff pair.

This doesn’t guarantee cleanup after arbitrary goroutine panics, `os.Exit`, or SIGKILL. An outer defer cannot provide that guarantee either.
