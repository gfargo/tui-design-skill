**Remove the defer.** `RestoreTerminal()` resumes Bubble Tea’s terminal modes after `ReleaseTerminal()`; it does **not** restore the user’s shell. Calling it after `Run()` can undo shutdown cleanup.

Use:

```go
p := tea.NewProgram(model)
_, err := p.Run()
return err
```

`Run()` owns terminal cleanup on normal exit, errors, and panics handled by Bubble Tea’s default recovery. Keep that recovery enabled; an outer defer cannot recover panics in arbitrary goroutines.

For temporary terminal handoff to an editor or shell, use `tea.ExecProcess(...)`. Reserve `ReleaseTerminal()` / `RestoreTerminal()` for manual handoffs that must resume the TUI.

No cleanup pattern can guarantee restoration after `SIGKILL` or `os.Exit`; avoid calling `os.Exit` while the UI is running.
