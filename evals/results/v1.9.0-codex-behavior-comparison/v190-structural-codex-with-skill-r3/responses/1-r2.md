I’d make responsive behavior a release blocker, then remove redundant chrome and status decoration. The namespace → resource → YAML workflow fits a full-screen browser; the resource list should get most of the space.

1. **Make the resource list usable at small sizes.** Wide monitors still host tmux splits and SSH sessions. Use this degradation plan:

   | Size | Layout |
   |---|---|
   | 120+ columns | Namespaces, resources, YAML; resources widest |
   | 80×24 | Full-width resources; namespace picker and YAML open on demand |
   | 60 columns | Single-pane drill-down; Enter opens YAML, Esc returns |
   | Below a tested minimum, initially 60×12 | Show “Requires 60×12; current W×H” and retain quit handling |

   Preserve selection, filters, and scroll position across resizing. Truncate table cells without wrapping; offer horizontal scrolling in YAML.

2. **Remove the double-line outer frame.** Your border-nesting depth is **2**: outer frame plus pane border. The terminal already supplies the outer boundary. Keep single-line pane borders only where they separate views or communicate focus.

3. **Cut repeated row decoration.** Readiness currently has **three signals**: `[READY]`, green, and a checkmark. Keep a plain `Ready` status, optionally green; remove brackets and checkmarks. The bullet appears on **100% of rows**, so remove it too. Use reverse video for the selected row. For Kubernetes, show resource-specific facts—such as pod `1/1 Running`—rather than implying every resource kind has the same readiness semantics.

4. **Replace 18 permanent shortcuts with contextual help.** Show about five common actions for the focused pane, plus `? Help`; put the complete keymap in searchable help. Two footer rows consume **8.3% of a 24-row screen**, before borders and headers. A one-row footer returns space to resources.

```text
Namespaces | Resources [focused] | YAML        NAME                 READY STATUS

           | worker 0/1 Pending |   ...       
                                              Enter YAML  n Namespace  / Filter
Tab Focus  / Filter  Enter YAML  ? Help        ? Help  q Quit
```

Also keep cluster and namespace visible in every view, distinguish pane focus without relying on color, and retain selection by resource UID during refreshes so updates cannot silently change the action target.

Before shipping, verify loading, empty, forbidden, disconnected, and stale-data states; pinned frames at 140 columns, 80×24, and 60 columns; monochrome/`NO_COLOR`; and terminal restoration on exit and interruption. From the description alone, those behaviors remain unverified.
