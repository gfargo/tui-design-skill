Use Textual’s **Pilot** to interact with your app inside `app.run_test()`. It runs without opening a terminal and works with `pytest-asyncio`:

```bash
pip install pytest-asyncio
```

Assuming your app has widgets with IDs `name`, `category`, `submit`, and `error`, and posts a custom `EntrySubmitted` message:

```python
# tests/test_entry.py
import pytest
from textual.widgets import Input, Select, Static

from my_app import EntryApp, EntrySubmitted


@pytest.mark.asyncio
async def test_empty_name_shows_error():
    app = EntryApp()

    async with app.run_test() as pilot:
        app.query_one("#name", Input).value = ""
        app.query_one("#category", Select).value = "personal"
        await pilot.pause()

        await pilot.click("#submit")
        await pilot.pause()

        error = app.query_one("#error", Static)
        assert error.display
        assert "Name is required" in str(error.render())


@pytest.mark.asyncio
async def test_submit_posts_message():
    received: list[EntrySubmitted] = []

    def capture(message):
        if isinstance(message, EntrySubmitted):
            received.append(message)

    app = EntryApp()

    async with app.run_test(message_hook=capture) as pilot:
        await pilot.click("#name")
        await pilot.press("A", "d", "a")
        app.query_one("#category", Select).value = "personal"
        await pilot.pause()

        await pilot.click("#submit")
        await pilot.pause()

        assert len(received) == 1
        assert received[0].name == "Ada"
        assert received[0].category == "personal"
```

Replace the imports, IDs, Select value, error text, and message attributes with your app’s actual names. `message_hook` observes messages dispatched by Textual, so this tests your custom submission message as it travels through the app.

A few details matter:

- **Use `await pilot.pause()` after interactions** so pending messages and screen updates finish before assertions.
- Set a valid Select value in the empty-name test to isolate name validation.
- Assigning `.value` is useful for setup; `pilot.press()` exercises keyboard input.
- If you use an `Input` validator, make sure empty input is actually validated: `valid_empty=True` explicitly treats it as valid. Your submit handler should validate before posting `EntrySubmitted`.

You can also capture messages in the first test and assert none were submitted, verifying that validation blocks submission.
