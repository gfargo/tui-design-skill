For a small “pick a recent branch” helper, I’d use a compact inline picker, perhaps 8–12 rows tall. Full-screen makes sense for a workspace like lazygit; a single selection benefits from keeping the surrounding terminal context visible.

After selection, replace the picker with one permanent summary line:

```text
$ branch-pick
Selected branch: feature/auth-refresh
$
```

On cancellation, remove the picker and either print nothing or leave a short `Cancelled.` message. Don’t leave the filtered list or highlighted rows behind.

The terminal detail that matters is the **alternate screen buffer**:

- **Inline, normal buffer:** keep the command visible, redraw only the rows your picker owns, then replace those rows with the summary.
- **Full-screen, alternate buffer:** the picker disappears when you leave that buffer. Restore the normal buffer **first**, then print the summary there. The original command and the summary will remain in scrollback.

For Go, choose a TUI library that supports inline rendering and avoid enabling alternate-screen mode by default. Always restore cursor visibility and terminal input settings on exit.

If the helper also supports `branch=$(branch-pick)`, reserve stdout for the raw branch name and render the UI through stderr or `/dev/tty`. A selection captured by the shell won’t automatically appear in scrollback; print a human-readable summary to the terminal if you want that behavior in this mode too.
