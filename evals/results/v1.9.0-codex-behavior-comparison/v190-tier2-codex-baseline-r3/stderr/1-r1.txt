Use Textual’s **`App.run_test()`** with its **Pilot** to interact with widgets. It runs headlessly, so you don’t need a terminal or screenshots.

Add pytest’s async support:

```bash
pip install pytest-asyncio
```

Here’s a pattern to adapt. Assume your app has:

- `Input(id="name")`
- `Select(id="role")`, with an option whose value is `"admin"`
- `Button(id="submit")`
- `Static(id="error")`, updated to `"Name is required"` on invalid submission
- A custom `Submitted` message with `.name` and `.role` attributes

```python
# tests/test_form.py
import pytest
from textual.widgets import Input, Select, Static

from my_app import MyApp, Submitted


@pytest.mark.asyncio
async def test_empty_name_shows_validation_error():
    messages = []
    app = MyApp()

    async with app.run_test(message_hook=messages.append) as pilot:
        # Supply a valid role so this tests only name validation.
        app.query_one("#role", Select).value = "admin"
        app.query_one("#name", Input).value = ""

        await pilot.click("#submit")
        await pilot.pause()

        error = app.query_one("#error", Static)
        assert error.display
        assert error.visible
        assert str(error.content) == "Name is required"

        # Invalid submissions must not produce a success message.
        assert not any(isinstance(m, Submitted) for m in messages)


@pytest.mark.asyncio
async def test_submit_posts_expected_message():
    messages = []
    app = MyApp()

    async with app.run_test(message_hook=messages.append) as pilot:
        await pilot.click("#name")
        await pilot.press(*"Ada")

        app.query_one("#role", Select).value = "admin"
        await pilot.pause()

        await pilot.click("#submit")
        await pilot.pause()

        submitted = [m for m in messages if isinstance(m, Submitted)]
        assert len(submitted) == 1
        assert submitted[0].name == "Ada"
        assert submitted[0].role == "admin"
```

`message_hook` observes messages without replacing `post_message`, so normal dispatch still runs. Filter by your custom message class because it also receives Textual’s internal messages.

Setting `Select.value` directly keeps these tests focused on your form logic. To exercise selection through the keyboard too, replace that assignment with:

```python
await pilot.click("#role")
await pilot.press("home", "down", "enter")
```

The keys depend on option order and whether you allow a blank selection. Use `pilot.pause()` to let pending events settle; avoid arbitrary `asyncio.sleep()` calls.
