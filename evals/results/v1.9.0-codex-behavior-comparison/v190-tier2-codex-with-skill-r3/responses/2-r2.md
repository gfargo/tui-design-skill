Check these likely causes:

- Recompute layout from `frame.area()` every draw. Queued resize-event dimensions can already be outdated.
- `Rect::bottom()` is **exclusive**. A panel’s last occupied row is `bottom() - 1`; adjacent rectangles should satisfy `body.bottom() == footer.y`.
- Borders occupy cells **inside** the panel rectangle. Use `Block::inner(panel)` for its contents; don’t add a row for the bottom border.
- In Tokio, keep terminal drawing and UI state mutation under one owner. Input/background tasks should send messages; a resize must mark the UI dirty.

```rust
fn compute_layout(area: Rect) -> (Rect, Rect) {
    let [body, footer] = Layout::vertical([
        Constraint::Min(0),
        Constraint::Length(1),

}
```
