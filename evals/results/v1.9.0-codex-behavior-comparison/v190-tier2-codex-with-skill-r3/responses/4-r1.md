**Use a bounded inline picker by default.** This is a summon–choose–exit tool: keeping the shell command visible helps users stay oriented. Reserve lazygit-style full-screen mode for a future workflow with a large diff or commit preview. For comparison, fzf defaults to full screen; its `--height` mode is the useful model here.

Cap the picker at roughly 8–10 lines, shrinking with terminal height:

```text
Wide terminal                           60-column split
$ recent-branch                         $ recent-branch
filter: fix                             filter: fix
> fix/login-redirect       2 hours ago   > fix/login-redirect
  fix/cache-key            yesterday      fix/cache-key
Up/Down move | Enter pick | Esc cancel   Up/Down move | Enter pick | Esc cancel
```

At 80×24, keep the same single list. At 60 columns, drop age metadata first; truncate long names by terminal cell width while retaining the complete selected value. Shrink the visible row count in short windows. Below a declared minimum such as 30×5, show a size message and keep cancellation working.

**On exit, replace the transient picker with a permanent result.** The terminal should look like:

```text
$ recent-branch
fix/login-redirect
$ _
```

Preserve the original command line; erase only the picker’s own rows. Don’t clear the terminal or leave the last menu frame behind.

Define the streams explicitly:

- **stdout:** the exact selected branch plus a newline, with no labels or ANSI styling.
- **stderr or `/dev/tty`:** the interactive picker and diagnostics.
- **Cancellation:** no branch on stdout; return a documented nonzero status.

For `branch=$(recent-branch)`, stdout is captured, so it cannot also provide the visible receipt. If you want the selection visible in that case too, print `Selected: fix/login-redirect` to the UI terminal after cleanup. Avoid duplicating that receipt when stdout already displays the branch.

In Go, Bubble Tea fits well: inline rendering is the default; direct the UI with `tea.WithOutput(os.Stderr)` or an opened terminal. Store the selection, quit through the framework, and print the final output **after `Run()` returns**, once terminal modes and the cursor are restored.

Keep the layout spare: zero borders, one `>` selection marker, no per-row icons, and one controls line. The lasting artifact should be the command and the answer.
