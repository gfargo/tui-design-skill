user
I want nice icons in my Ratatui app (Nerd Font glyphs) but I'm worried about users who don't have one installed — what's the right way to handle this, and separately: my app polls a remote API every few seconds and sometimes it times out — what should the UI do?

codex
For icons, make Nerd Fonts optional and give users an explicit override. There’s no reliable, portable way to detect which font a terminal uses or whether it contains a particular glyph.

- Support `icons = auto | nerd | plain`, plus a flag such as `--icons plain`.
- Make `auto` choose a conservative plain set unless the user has opted into Nerd Fonts. `$TERM`, locale, and Unicode support don’t prove Nerd Font availability.
- Keep labels meaningful without icons: `✓ Connected` can become `[OK] Connected`.
- Test alignment in both modes. Nerd Font glyphs can render at different widths across terminals; avoid relying on them for borders or precise spacing.

Document the recommended font and show an icon preview in settings so users can choose what renders correctly.

For API timeouts, **keep the last successful data visible and clearly mark it as stale**. A failed refresh shouldn’t turn a useful screen into an error screen.

A small status line can communicate the whole lifecycle:

```text
Refreshing… · Updated 8s ago
Refresh timed out · Showing data from 24s ago · Retrying in 10s
```

On the first load, when there’s no cached data, show a loading state, then a clear error with a retry action if it fails. For subsequent failures:

- Keep navigation and input responsive; run requests outside the Ratatui drawing/input loop.
- Allow only one refresh in flight, set a request timeout, and retry with capped exponential backoff and jitter.
- Offer manual retry, without letting repeated presses create overlapping requests.
- Avoid repeated popups or toasts. Use a persistent status indicator, and clear it when a refresh succeeds.

If users can act on the displayed data, make its age visible near consequential actions and disable actions that require fresh information when necessary.
