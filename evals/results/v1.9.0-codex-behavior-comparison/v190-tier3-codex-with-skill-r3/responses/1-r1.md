**Use a short, inline first-run setup, then continue the command they originally ran. Store the key in the OS credential store; Huh handles entry, not storage.**

When no key is configured:

1. **Explain the prerequisite and show where to get a key.** Link directly to the provider’s key creation page.
2. **Ask for one masked input.** Allow paste, reject empty input, and show Enter/Ctrl+C controls. Skip unrelated preferences and welcome screens.
3. **Validate with a lightweight authenticated request**, if the API supports one. Keep network work outside Huh’s field validator. Distinguish “key rejected” from “couldn’t reach the service”; a timeout doesn’t prove the key is invalid.
4. **Save, confirm the storage location, and resume.** Only say “saved” after storage succeeds. Cancellation leaves storage unchanged and exits unsuccessfully.

Keep `--help`, `--version`, and authentication repair commands available without a key.

At 80×24 or a 60-column tmux split, this stays a single column; wrap explanatory text and horizontally scroll the input. No borders, banners, repeated markers, or color-dependent meaning are needed. Offer an accessible linear prompt mode through Huh’s `WithAccessible(true)` and verify secret entry remains hidden.

**For persistence, default to the platform credential store**, accessed through a Go library such as [`zalando/go-keyring`](https://github.com/zalando/go-keyring):

- macOS: Keychain
- Windows: Credential Manager
- Linux: Secret Service, when available

Use a stable service name and an account/profile identifier as the lookup key. Keep ordinary settings and profile metadata in your config file.

Document credential precedence, for example:

```text
MYCLI_API_KEY environment variable > saved credential
```

The environment variable supports CI and headless use; don’t automatically persist its value. Avoid a `--api-key VALUE` flag because it exposes secrets through shell history and process arguments.

If the credential store is unavailable or locked, explain the failure and offer an environment variable or an **explicitly chosen** file fallback. Never silently downgrade to plaintext. A file fallback should use a private directory and restrictive permissions (`0700`/`0600` on Unix; appropriate ACLs on Windows).

**Without an interactive terminal, never launch the wizard or consume piped stdin.** Exit nonzero with a useful stderr message:

```text
error: no API key configured.
Set MYCLI_API_KEY or run `mycli auth login` interactively.
```

Route prompts and setup receipts to stderr or the controlling terminal; reserve stdout for command results. Provide `auth login`, `auth status` that never reveals the key, and `auth logout` for replacement and removal.
