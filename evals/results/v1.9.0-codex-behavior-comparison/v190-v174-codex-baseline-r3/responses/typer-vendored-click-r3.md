Typer builds on Click, so you can attach Trogon to the Click command generated by your Typer app.

Install the dependencies:

```bash
pip install typer trogon
```

Keep defining commands with Typer, then convert the app to Click and apply Trogon at the entry point:

```python
# cli.py
import typer
from trogon import tui
from typer.main import get_command

app = typer.Typer()


@app.command()
def greet(name: str, count: int = 1):
    """Greet someone."""
    for _ in range(count):
        typer.echo(f"Hello, {name}!")


@app.command()
def status():
    """Show application status."""
    typer.echo("Everything looks good.")


# Typer → Click → Trogon
cli = tui()(get_command(app))

if __name__ == "__main__":
    cli()
```

Users can run either the normal CLI or the TUI:

```bash
python cli.py greet Alice --count 3
python cli.py tui
```

For a packaged application, point the console script at the decorated Click command:

```toml
[project.scripts]
myapp = "my_package.cli:cli"
```

Then users launch the interface with `myapp tui`.

The key is to **invoke `cli()`, rather than `app()`**, after attaching Trogon. Calling `app()` builds another Click command without the added TUI command.

Two details to watch:

- **Single-command apps:** Typer normally collapses these into a standalone command. Add an `@app.callback()` if needed to force a command group, so there’s a place for the `tui` subcommand.
- **Other Click plug-ins:** The same conversion works for plug-ins that decorate or modify a Click command. Plug-ins requiring custom Click classes may need integration through Typer’s `cls=` options instead.
