Use **[`ratatui-textarea`](https://crates.io/crates/ratatui-textarea)**, the Ratatui organization’s maintained fork of `tui-textarea`. It supports **Ratatui 0.30**, multi-line editing, and vim/emacs-style bindings.

```sh
cargo add ratatui-textarea
```

Avoid the original `tui-textarea` for this app: it is unmaintained, and its last release, 0.7, targets Ratatui 0.29.

Official repository: [ratatui/ratatui-textarea](https://github.com/ratatui/ratatui-textarea).
