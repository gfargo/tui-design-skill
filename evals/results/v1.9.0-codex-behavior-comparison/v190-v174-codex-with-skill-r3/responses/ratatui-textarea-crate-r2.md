Use **[`ratatui-textarea`](https://crates.io/crates/ratatui-textarea)**, the Ratatui organization’s maintained fork of `tui-textarea`. It provides a multi-line editor with vim/emacs-style bindings and supports **Ratatui 0.30**.

```sh
cargo add ratatui-textarea
```

Avoid the original `tui-textarea`: it is unmaintained, and its last release, 0.7, requires Ratatui 0.29.

Official repository: [ratatui/ratatui-textarea](https://github.com/ratatui/ratatui-textarea).
