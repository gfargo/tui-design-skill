My Ratatui confirm dialog is a bordered Paragraph rendered over the main view, but the text underneath shows through the blank parts of the dialog. How do I center it and fix that, and can I give it a drop shadow?

codex
Render `Clear` before the dialog. A `Paragraph` only paints its text and border; `Clear` erases the main view underneath the entire popup area.

You can center a fixed-size dialog with rectangle arithmetic and simulate a shadow with an offset background rectangle:

```rust
use ratatui::{
    layout::Rect,
    style::{Color, Style},
    widgets::{Block, Borders, Clear, Paragraph, Wrap},
    Frame,
};

fn confirm_dialog(frame: &mut Frame) {
    let screen = frame.area();
    let width = 46.min(screen.width);
    let height = 7.min(screen.height);

    let popup = Rect::new(
        screen.x + (screen.width - width) / 2,
        screen.y + (screen.height - height) / 2,
        width,
        height,
    );

    let shadow = Rect::new(
        popup.x.saturating_add(2),
        popup.y.saturating_add(1),
        popup.width,
        popup.height,
    )
    .intersection(screen);

    // Paint order: main view → shadow → popup.
    frame.render_widget(Clear, shadow);
    frame.render_widget(
        Block::default().style(Style::default().bg(Color::DarkGray)),
        shadow,
    );

    frame.render_widget(Clear, popup);
    frame.render_widget(
        Paragraph::new("Delete this item?\n\n[y] Confirm    [Esc] Cancel")
            .wrap(Wrap { trim: true })
            .block(
                Block::default()
                    .title(" Confirm ")
                    .borders(Borders::ALL),
            )
            .style(Style::default().fg(Color::White).bg(Color::Black)),
        popup,
    );
}
```

Call this **after rendering your main view**.

The shadow is a solid terminal-cell effect. Ratatui doesn’t provide alpha blending or blurred shadows; choose a background color that contrasts with your main view.
