|---|---|

| `Page Up` / `Page Down` | Move one viewport, keeping one row of overlap |
| `Home` / `End` | Jump to the first / last item |
| `j` / `k` | Optional aliases for down / up, outside text inputs |
| Mouse wheel | Scroll a few rows |
