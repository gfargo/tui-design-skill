In my file manager, the list has 3,000 files and the user has marked 14 of them. They press d. Design the confirmation. Show it as a plain-text sketch on an 80-column terminal, and say what each key does.

codex
```text
+------------------------------------------------------------------------------+
| Delete 14 marked files?                                                      |
|                                                                              |
| Only the marked files will be deleted.                                       |
| The other 2,986 files will stay.                                              |
|                                                                              |
|                         [ Cancel ]    Delete 14 files                        |
|                                                                              |
| Enter / Esc / n: cancel                         y: delete 14 marked files    |
+------------------------------------------------------------------------------+
```

- **Enter, Esc, or n:** Cancel; preserve all marks and return to the list.
- **y:** Delete exactly the 14 marked files.
- **d and other keys:** Do nothing, so a repeated `d` cannot confirm accidentally.

Keep **Cancel** as the default. If deletion bypasses Trash, explicitly say **“Permanently delete”** and **“This cannot be undone.”**
