In my file manager, the list has 3,000 files and the user has marked 14 of them. They press d. Design the confirmation. Show it as a plain-text sketch on an 80-column terminal, and say what each key does.

codex
```text
+------------------------------------------------------------------------------+
| Delete 14 marked files?                                                      |
|                                                                              |
| Only the 14 marked files will be deleted.                                    |
| The other 2,986 files will remain unchanged.                                  |
|                                                                              |
| [ Enter / Esc / n: Cancel ]                         [ y: Delete 14 files ]    |
+------------------------------------------------------------------------------+
```

- **y** confirms deletion of exactly the 14 marked files.
- **Enter**, **Esc**, or **n** cancels, preserving the marks.
- **d** and other keys do nothing, so a repeated `d` cannot confirm accidentally.

If deletion bypasses Trash, add **“This cannot be undone.”** before the buttons.
