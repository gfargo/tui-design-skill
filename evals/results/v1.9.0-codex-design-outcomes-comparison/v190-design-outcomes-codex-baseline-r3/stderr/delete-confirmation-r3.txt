In my file manager, the list has 3,000 files and the user has marked 14 of them. They press d. Design the confirmation. Show it as a plain-text sketch on an 80-column terminal, and say what each key does.

codex
```text
+------------------------------------------------------------------------------+
| Delete 14 marked files?                                                      |
|                                                                              |
| Only the 14 marked files will be deleted. The other 2,986 files will stay.     |
|                                                                              |
| [ Cancel ]                                     Delete 14 files (y)            |
|                                                                              |
| Enter / Esc / n: cancel                        y: confirm deletion            |
+------------------------------------------------------------------------------+
```

- **Enter, Esc, or n:** Cancel; preserve all marks and return to the list.
- **y:** Delete exactly the 14 marked files.
- **d and other keys:** Do nothing, so repeating the original shortcut is safe.

Cancel is the default. If deletion bypasses Trash, add **“This cannot be undone.”** before the buttons.
